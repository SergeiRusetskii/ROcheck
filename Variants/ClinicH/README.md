# ROcheck ClinicH

This variant targets Varian Eclipse 16.1 and keeps a compatibility-focused implementation for the shared ROcheck validation set.

## Scope

- Eclipse 16.1 compatibility
- Shared validation infrastructure from `Core/`
- Variant-specific validators and settings under `Variants/ClinicH/`

## Validation Coverage

- Clinical goals coverage
- Target containment
- PTV and OAR overlap conflicts
- Target resolution checks
- Structure type validation
- SIB dose unit validation
- PTV to body proximity checks
